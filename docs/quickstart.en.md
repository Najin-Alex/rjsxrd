# Quick start

Two steps to start using the configs.

## Step 1. Copy the link

Recommended files to get started:

| File | Link |
|------|--------|
| 1.txt | `https://raw.githubusercontent.com/whoahaow/rjsxrd/refs/heads/main/githubmirror/default/1.txt` |
| bypass-all.txt | `https://raw.githubusercontent.com/whoahaow/rjsxrd/refs/heads/main/githubmirror/bypass/bypass-all.txt` |
| all-secure.txt | `https://raw.githubusercontent.com/whoahaow/rjsxrd/refs/heads/main/githubmirror/default/all-secure.txt` |

**Which one to choose?**
- For mobile internet with whitelists (Russia, Uzbekistan, etc.) — `bypass/bypass-all.txt`
- For regular blocks — any file from `default/`, for example `6.txt`, `22.txt`, `23.txt`
- For minimal risk — `all-secure.txt` (only secure configs)

All links are collected in the [Generated files](user/config-files.en.md) section.

## Step 2. Import into a client

Copy the link to the clipboard and open your VPN client:

- **Android (v2rayNG):** `+` → "Import config from clipboard"
- **Windows (Throne):** "Profiles" → "Add profile from clipboard"
- **iOS (V2Box):** "Config" → `+` → "Add subscription"
- **macOS (Hiddify):** "New profile" → "Add from clipboard"

Detailed instructions with pictures — in [Import into clients](user/import-guide.en.md).

After importing, select the server with the lowest ping and connect.
